Created: 2026-03-01T17:45:00+07:00
Status: 🟡 In Progress

## Overview
Xây dựng 2 tính năng lớn để biến trang đọc truyện thành "Vũ trụ Mạt Thế":
1. **Wiki Bách Khoa:** Trang tra cứu thông tin Nhân vật, Sinh vật, Thế lực...
2. **Hệ thống Thả Tim (Like):** Độc giả bấm tim chương yêu thích (không cần đăng nhập).

## Phương châm
> "Code chắc phần Hậu trường (Admin) → Test → Mang ra Mặt tiền (Frontend)"

## Tech Stack
- Frontend: Next.js 15 (App Router), TypeScript, Tailwind CSS
- Backend: FastAPI (Python)
- Database: Supabase (PostgreSQL)
- Storage: Cloudflare R2 (ảnh wiki)
