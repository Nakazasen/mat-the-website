# New Chapters Intake Folder

Place raw chapter files here to be verified and ingested.

## File Format

- Filename: `chapter_XXXX.txt` (where `XXXX` is a 4-digit zero-padded chapter number).
- Content structure:
  - First line: The chapter title (e.g. `Chương 830: Bình Minh Khởi Đầu`)
  - Remainder: The text content of the chapter.

## Example File: `chapter_0830.txt`
```
Chương 830: Bình Minh Khởi Đầu

Diệp Phàm đứng trên đỉnh tòa cao ốc, nhìn về phía chân trời xa xăm...
Nội dung truyện được viết tiếp từ đây.
```
